# SnapCtrl app icon

The installed app uses the opaque Midnight icon in `docs/branding/app-icon.png` (1024px).
The browser favicon (64px), Apple touch icon (180px), PWA icons (192px/512px) and
maskable PWA icon (512px) are resized exports. The OS applies its own icon mask;
the source has no baked-in rounded corners. Its mark sits within the maskable safe
area. Both standard and Home Assistant manifests use these icons.

Created with the built-in ImageGen tool. Final prompt:

> Use case: logo-brand. Asset type: finished installable mobile PWA app icon for SnapCtrl, a multiroom audio controller. Create ONE square 1024 by 1024 pixel icon. Full bleed opaque deep midnight navy background (#0b1322), with very subtle smooth blue radial light for depth, NO rounded outer corners because the OS applies the icon mask. Center one distinctive bold geometric abstract audio mark: a beautifully balanced fluid S-like waveform made of five or six rounded vertical bars that rise and fall, subtly suggesting synchronized sound across rooms. Crisp precision edges, luminous ice blue to electric azure gradient (#a6d9ff to #428fff), restrained soft internal depth and gentle glow, premium minimal utility app identity, strong silhouette legible at 32 px. The audio mark must be contained entirely within the central 64% of the square for maskable safe area. Lots of clear navy margin. No words, no letters, no numbers, no border, no mockup, no phone, no perspective, no extra symbols, no music notes, no photographic textures, no watermark. Deliver only the finished single icon filling the entire canvas.
